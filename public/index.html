Try it right here

This is the real Nomen plugin interface, running on a sample design instead of your Figma file.

  1. Analyze Layers. Nomen finds every layer still carrying a Figma default name.
  2. Review. Confident names are pre-ticked. Best guesses sit under Needs review.
  3. Edit or untick anything you disagree with, or use Select all to accept everything.
  4. Rename. In Figma, the whole batch is one undo step.

The demo runs Nomen's built-in rules. In Figma, adding an Anthropic API key switches on Claude, which reads the whole design and produces context-aware names like “Payment Options Card”.

How Nomen thinks

A hybrid engine: fast rules for the obvious, AI for the ambiguous, and you for the final say.

1

Finds the mess

It only targets Figma default names like “Frame 12” or “Group 4 copy”. Names you chose on purpose are never touched.

2

Understands purpose

It reads text, component names, structure and siblings to name things by what they do: “Checkout Button”, not “Blue Rectangle”.

3

Never surprises you

Preview first, edit anything, one-click undo. If the AI fails or answers badly, your file stays exactly as it was.

Use it in Figma

Nomen runs as a development plugin in the Figma desktop app. Setup takes about two minutes.

  1. Download the code from GitHub (Code → Download ZIP) and unzip it.
  2. Open the Figma desktop app and any design file.
  3. Go to Menu → Plugins → Development → Import plugin from manifest… and choose manifest.json.
  4. Select a frame, then run Plugins → Development → Nomen.
  5. Optional: add an Anthropic API key under the gear icon for AI naming.
