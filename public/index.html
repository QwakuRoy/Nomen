    How it works

    Three steps. Zero busywork.

    1.0 Analyze

    Finds the mess

    Scans your selection for Figma default names like “Frame 12” or “Group 4 copy”. Deliberate names are left alone.

    2.0 Understand

    Names by purpose

    Reads text, components, structure and siblings, so it names a layer for what it does, not what it looks like.

    3.0 Approve

    You have the final say

    Review, edit or untick anything, then rename the whole batch in one click, and undo it in one step.

    Install

    Running in Figma in two minutes

    Nomen runs as a development plugin in the Figma desktop app. No build step, no account needed.

    Get it on GitHub
    1. Open the GitHub repo, then Code → Download ZIP, and unzip it.
    2. Open the Figma desktop app and any design file.
    3. Go to Menu → Plugins → Development → Import plugin from manifest… and choose manifest.json.
    4. Select a frame and run Plugins → Development → Nomen.
    5. Optional: add an Anthropic API key under the gear icon to switch on Claude.

    Clean up your next file in seconds.
